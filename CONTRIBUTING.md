# Contributing

Bug reports and ideas are welcome as GitHub issues.

Code contributions need a signed Contributor License Agreement before they can be merged. The agreement lets the project keep a single copyright holder, so it can be relicensed or offered under additional terms later; you keep the right to use your own contribution however you like. Open an issue saying what you'd like to change and we'll send the agreement.

By opening a pull request you confirm the work is yours to contribute.
