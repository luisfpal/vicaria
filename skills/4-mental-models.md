# Mental models to keep
> The reusable models in the text, how to use each, and where else they apply (Munger's latticework).

Extract the mental models a reader can reuse far beyond this book (Charlie Munger's latticework idea):
For each model (2 to 5):
- **Name** (short, memorable) and the model in one sentence.
- **Mechanism**: why it works, from the book's reasoning.
- **In the book**: the author's example, with the chapter.
- **Elsewhere**: two other domains where the same model applies. Mark [Inference].
- **Misuse**: the failure mode when applied blindly.
End with one line on how the models connect to each other.
