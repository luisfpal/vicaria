# Explain it simply (Feynman)
> The mechanism in plain words, as if to a bright friend who has not read it, with one concrete example.

Explain the material as Feynman would to a bright friend who has not read it:
1. **The idea in one plain sentence**, no jargon.
2. **How it works**: the mechanism or argument as a short chain of steps, each forced by the one before. Use the author's terms only after saying them plainly.
3. **One concrete example**, preferably the author's own; if you make one up, start it with [My illustration].
4. **Where the simple version breaks**: the one nuance the plain explanation leaves out.
